# Súper de la casa

Página para planificar el súper del mes: presupuesto, lista de compras y registro de lo que se compra.

Esta página no guarda datos. Las compras quedan en una planilla de Google privada, a la que se accede con la dirección de un script de Apps Script y una clave que solo se cargan en cada dispositivo. El script está en `apps-script/Code.gs` y las instrucciones para instalarlo, al principio de ese archivo.
